# Instrument research overlays — first isolated UI slice

## Source of truth

Every qualified market bar must originate from Bybit ingestion recorded in **Grid-owned PostgreSQL**; neither this viewer nor Terminan queries Bybit or the production database. For now, the only accepted import is synthetic `terminan.history.scientific-handoff.v1` generated by Strattester #65 from a `review_packet` checked against a caller-provided result receipt. Both provenance and receipt are caller supplied and **not** independent market authentication.

## User flow / temporal semantics

1. Choose Grid dataset identity, venue, symbol, fixed UTC interval, source receipts, completeness watermark and as-of snapshot (future development; historical export remains read only).
2. Run pinned Math #100 historical features/forecast or separately pinned Math #102 scientific DAG experiments. A cross-API adapter must not conflate these two commits or treat a different time axis as equivalent.
3. Freeze each hypothesis/model, source dataset, parameters, units, input availability and decision timestamp before scoring. Compare/compose hypotheses only in pinned Math; never in browser chart code.
4. Export Strattester read-only replay/forecast evidence with event-end, first-availability, watermark, decision and target event times.
5. Open `/history-overlay`, import the synthetic handoff JSON, choose UTC interval and `asOf`. Price points appear **only if available_at_ms <= asOf**. A forecast marker appears at its **target event time** only after the prediction's decision time. Forward mode only shows target events after `asOf`, never invents actual future candles.
6. For historical verification use chronological walk-forward: freeze prediction at decision time, then evaluate only against target observations known later, with costs/funding/capital in Strattester; keep train/validation/OOS distinct. Show measured skill versus baseline and warn on missing historical revisions, incomplete watermark or stale data.

## Current implementation

Static HTML/JS for synthetic price lines and forecast markers, two visibility toggles, time range and causal `asOf` controls, a history/forward switch and explicit UNATTESTED flags. No production SQL connector, automatic latest-Bybit feed, OOS scoring UI, live strategy prediction or multi-model weights yet. Neither Math API is invoked by this display component.

Security properties: 2 MiB import limit; <=2000 rows of each type; strict finite positive values; safe integer UTC clocks; source `event <= watermark <= available` and forecast `event <= available <= decision < target`; false authority flags. Values are used via SVG DOM APIs / textContent, not innerHTML. **These are structural checks only**, not independent SHA256 verification of the packet; local hashes can be forged, and the page must never label real provenance VERIFIED.

## Compatibility

Terminan #53 remains pinned to Math #102 and retains current `/math`. This Draft extends that source but does not alter the working ADMINIT checkout. Strattester Draft #65 produces the synthetic envelope via `scripts/export_history_scientific_handoff.py`. A future qualified read-only Grid PostgreSQL adapter and true multi-scientific-layer display require separate independently reviewed code and source receipts.
