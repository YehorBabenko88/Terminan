# Pure research performance reporting v1

Consume typed rich-entry evaluation, preserving all entries and outcomes. Snapshot the complete bounded exact record/context/numeric/coverage graph before any Math callback. Reuse canonical rich-entry admission; no selection or execution path is added.

A closed declaration batch keys optional Decimal MAE/MFE/R and coverage by symbol+unique decision clock. Unknown, unused, duplicate or future keys refuse. Missing declarations stay absent, not zero. Units are explicit caller declarations; metric units are required when values exist. Coverage COMPLETE_HISTORY/PARTIAL_HISTORY/UNCLASSIFIED never grants completeness or source authority.

All filled outcomes are summarized using actual PaperFill Decimal gross/net/fees, explicit Math Decimal-to-binary64 projection, then Math001 numeric_trade_summary. Partition by declared coverage and by actual retained volatility regime with a separate missing bucket. Partition trade IDs conserve the all-filled set. Holding is modeled exit-minus-entry bar-start clocks, never availability duration. Do not infer excursions.

The immutable report retains captured evaluation and exact per-trade entry/outcome associations, source uncertainty, declared units and config. Fingerprint binds full literal input, declarations, Math ABI/API/policies and metadata. Closed finite serialization refuses unsupported/nonfinite outputs. Persistence and legacy Data caller migration/deletion are excluded; legacy516/NO_GO remain. Alternative loose metadata/getattr or reused net gain partitions would erase missing values and confuse gross accounting; rejected.
