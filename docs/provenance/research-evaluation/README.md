# Offline research evaluation v1

This prototype orchestrates the existing PaperEngine, ResearchSignal admission, Math exact accounting, Math descriptive summaries and Terminan research screening. It creates no endpoints, accounts, ledger, environment configuration, provider connection or source attestation. Dataset SHA, symbol, units and availability are caller declarations. Execution/trading authority and OOS/PIT qualification remain false. No legacy TradeMetrics retirement or whole legacy-test equivalence is claimed; remaining declared legacy functions stay 516.

Every input and policy leaf is captured before Math. The finite plain Decimal resource codec allows at most 64 coefficient digits and exponents -128..128; financial validation and arithmetic stay with Math. The canonical SHA256 retains signed zeros and trailing zeros and binds all inputs, folded windows/account policy, availability policy, ambiguity, Math ABI, fees/notional/slippage and seeded IID bootstrap policy (500,17,.95). The descriptor cap is 8 MiB.

Folds partition actual candle indices [i*N//folds:(i+1)*N//folds], preserve empty outcome populations and reset independent accounts. Embargo removes complete bars with start below fold start+embargo. Market decisions use first start>=decision; limits keep canonical strict next boundary. One private enabled engine simulates each fold; no second simulator computes fills. Every signal gets FILLED, NOT_FILLED, POSITION_OCCUPIED or OUTSIDE_TEST_WINDOW. Filled account release is the maximum caller-declared availability among all entry-search/exit dependency bars. An unresolved limit reserves the slot until both fold end and all page availability. Equality at release allows the next offer. All candles are fully closed and known as of the declared snapshot. EOD closure and independent fold resets do not represent a real continuous portfolio or fitted OOS evaluation.

Only the canonical no-entry-filled branch changes to a typed SignalNotFilled(ValueError); other admission/Math failures abort the entire local evaluation. Existing engine arithmetic is unchanged. The workload cap is 512 signals,4096 candles and conservative 4*S*N+N<=1,000,000 row visits. Exact fill.net is projected explicitly to rounded binary64 only for descriptive Math PnL summaries and IID uncertainty. A screening KEEP with bootstrap lower<=0 downgrades to NEEDS_MORE_DATA/BOOTSTRAP_CROSSES_ZERO.

Intentional differences from the old permissive evaluator: no silently discarded errors, no independent overlapping fills, no omitted unfilled/outside signals, strict whole-input preflight, actual availability, candle-index folds and canonical conservative intrabar policy. No source-authentication, PIT, fitted-OOS or physical execution claim follows.
