# Declared research screening transfer

Terminan owns canonical generator selection, group labels and screening verdict policy. Math owns fold arithmetic, fractions, ordered means and sample summaries. No secondary simulator, data store, numerical kernel or dynamic strategy loader is introduced.

Original strict thresholds and ordered reason codes are retained. Fold means remain unweighted. The explicit LEGACY_LT_1E100_V1 factor policy excludes large/sentinel factors; no eligible factor is None and policy rejects it, without fabricating an observed zero. ORDERED_BINARY64_V1 is explicit and stable across Python versions.

Input IDs are canonical catalog IDs; specification-only entries cannot enter generator screening. Inputs are bounded literal batches and immutable Math fold records. Caller units are explicit for segment values; nothing infers currency, data quality, availability or source authentication. A result KEEP is only a research recommendation and grants no trading/execution authority. No verified OOS/PIT fitting is claimed.

Differences from old permissive code: unknown IDs/coercible objects/generators/non-finite values are rejected; segmentation materializes all input leaves before Math calls and never exhausts an iterator between dimensions. Missing group labels are explicit UNKNOWN. All dimensions use one provided value unit.

Three original screening assertions are represented across canonical catalog and screening tests. Old Data module/test and pattern evaluation remain until every caller/unique role is migrated and independently accepted; no decrease from516 obligations.
