# Supervisor status consumer v1 (Draft)
An opt-in loopback-only GET consumer for the Unified Supervisor v1 health envelope. It never sends commands or grants trading authority. Default is UNAVAILABLE when not configured. This implementation is a candidate and does not yet integrate into the main Terminan dashboard. A five-second deadline watchdog and bounded reads are implemented; this is not yet independently proven against all socket-assignment races or hostile slow-header peers. Further bounded-transport review is required before deployment. No physical G0/G1, services, DB writes or exchange access.
